## 🎯 〇、十条核心结论（每条带证据）

**1. 组合压倒单项**：固定模型换 harness 的性能方差，是固定 harness 换模型的 7.80 倍（SWE-bench 3×3 受控实验 🟢）；9 组比较 6 组发生模型排序翻转。💡 **对你的直接含义：主模型降级省成本是对的——省下的钱该花在装备层，不是模型层。**

**2. 减法是性价比之王**：Vercel 工具 18→2（计数 🔵，ZenML 转录；旧稿误作 15→2，见 references.md C），成功率 80%→100% 🟢；Anthropic 用代码执行替代直连 MCP，工具开销 150K→2K token（-98.7%）🟢。

**3. 先建回路再加能力**：harness 增益主要来自「校验+恢复回路」而非更强模型/更多工具；加一个独立验证步骤，任务成功率 +15.6%（MAST 🟢）。

**4. 记忆的价值在治理不在容量**：图谱记忆 vs 扁平向量整体 F1 反而 -0.050 ⚪⚠️（审计未定位一手出处，且 MOSAIC 2607.16211 主张结构化记忆更优、方向相反，见 references.md E——此句存疑，待维护者补证）；记忆写入无准入 → 注入攻击成功率 37-64% 🔵。「什么都记」= 不加分只加险。

**5. 技能价值在粒度与准入门不在数量**：人写技能 +16.2pp、模型自写 -1.3pp（低于无技能基线）🟡；带真实执行回放准入门的技能库 +17.2pp、12/12 全胜（p=0.000488，n=12 最小可达值）🟢。

**6. 模型自演化会集体漏掉「状态与校验」**：6 个前沿模型自建 harness，77.8% 失败归因于 harness 缺陷而非执行模型 🟢；18 个 code harness 中 0 个 checkpoint 事件、441 个退化提交无人检测——自我改进系统必须外部强制注入状态持久化与独立校验。

**7. 自评自改的经济学**：自我改进管线几乎所有算力花在「测量」——一次运行中评估消耗约 4500 万 token，真正产生改进的推理只占约 0.03% 🔵；agent 靠读缓存答案拿到 100% 满分、掩盖 68% 真实能力 🔵。评估不可靠 = 整个系统不可靠。

**8. 多 agent 是方向对才有效**：广度型只读探索拆多 agent +90.2%（Anthropic 内部 eval 口径，打折看，token 消耗是聊天的 15 倍）；上下文耦合的决策链拆多 agent 会因「隐含决策丢失」而崩 🟢。💡 裁决：可并行的只读探索→拆；决策链→单 agent+子agent只回摘要。

**9. 智能路由天花板比想象低**：21 种路由方法在 5 个基准上 top5 只差 0.22pp、离 oracle 差 10-30pp 🟢；但一个便宜的「置信度门控」就能拿到 78.0%（45K token）vs 冻结路由器 73.8%（71.3K token）⚪（一手出处待补，见 references.md E）。💡 **复杂 combo 常被简单规则打败；主模型+fallback+按任务分池就是最优形态的近似。**

**10. 递归派生有风险相变**：局部错误率超过临界点，整条任务线危害概率从 9.68% 跳到 51.86%（不可灭绝下限 51.10%）⚪（一手出处待补，见 references.md E）。派生要自由，授权必须逐级收紧。

## 🧭 一、四层框架：能力装在哪层，效果完全不同

| 层 | 回答的问题 | 包含维度 |
|---|---|---|
| 🧠 模型智能层 | 基座本身多强 | 模型能力、提示词调用 |
| 🧰 Harness 层 | 模型周围的装备 | 搜索、记忆、工具、skill、知识库、上下文、模型路由 |
| 🔄 Loop 层 | 单次运行怎么转 | 规划、校验、复盘修复、迭代改善、执行纪律 |
| 🕸️ Graph 层 | 多个怎么组织 | 独立验证、多 agent 编排、灰度评测、权限分级 |

💡 **关键区分：同一能力装在不同层，效果完全不同。** 「校验」装在 Loop 层 = 自我反思（弱，同一模型自检有自我确认偏差）；装在 Graph 层 = 独立验证节点（强，MAST +15.6% 实证）。「记忆」装在上下文里 = 污染；外置文件+按需检索 = 资产。

## ✅ 二、正例组合 C1-C8（按证据强度）

- **C1 技能×执行门（最强证据）**：攒技能卡（任务+签名+轨迹+验证分）→ 按「怎么解」聚类 → 压缩成「适用条件/步骤/失败模式」三段式 → 真实回放 ≥ 在位版本-0.02 才入库 🟢。对比无门自写技能 -1.3pp（SkillsBench 🟡）。技能选择侧：Progressive Disclosure（启动只载名字，激活才载全文）已是共识 🟡。
- **C2 工具×代码执行×文件系统**：工具定义变文件树按需读取，150K→2K token（-98.7%）🟢；循环/条件/错误处理在沙箱里跑，模型只看最终结果；顺带隐私收益（中间数据不进上下文）🟡。
- **C3 校验×位置在图不在环**：独立 verifier 节点/角色 + 确定性门话语权高于 LLM 裁判（PROCTOR 五层护栏 🔵；MAST +15.6% 🟢）。
- **C4 记忆×遥测×淘汰公式**：同一份 access/visit 日志三处复用——记忆淘汰（recency 0.35/freq 0.25/centrality 0.20/age 0.20 起步 🟢）、检索去冗余（ITER 冗余负例贡献最大消融：去掉 -5.8pp 🔵）、技能准入 🔵。统一遥测层是四个维度共用的货币。
- **C5 搜索×假设分支×证据聚合**：HypoSearch——发散状态下 ≤5 条软假设并行有界搜索、聚合比证据不比答案，+13.3pp 且比多数投票省 29-35% 工具调用 🔵。
- **C6 模型×降级链而非智能路由**：主模型+fallback+任务分池 ≈ 路由器效果且更便宜（路由增益大部分只是任务类型：21 种方法 top5 差 0.22pp 🟢 + 置信门控 78.0%@45K ⚪，一手出处待补，见 references.md E）。
- **C7 评估×早停**：EarlyEval 提前终止注定失败/成功的 run，省 13-26% 步数、44% 输入 token，预测准确率 89-97% 🔵。
- **C8 组合进化（StarHarness）**：LLM 出假设、程序化 verifier 做验收门（环境状态断言、违规即零分）——harness 进化 +20-35pp，只需 4-12 个被接受的改动；进化产物跨模型可迁移（33.1%→79.4%，+46.3pp）🟢。对照：HarnessDev 让模型自由自改，held-out 与反馈同向率仅 53.1%（掷硬币级）。⚠️ **反证校准**：2607.12227（Rethinking the Evaluation of Harness Evolution for Agents）指出 harness 进化**不能稳定赢过** test-time scaling、新任务泛化有限——+20-35pp 依赖任务分布与基线强度，非普适，跨任务/跨模型须重测（见 references.md D）。

💡 **C8 的深意：自我进化的正确形态至此闭环——LLM 出假设，确定性门出判据**（与 C1 同构，作用对象从技能升到了整个 harness）。企业实测附带彩蛋：任务成功率 23.3%→43.7%、单任务成本 $1.23→$0.58（-53%）——**好的组合不是省钱和变强二选一**。

## ☠️ 三、杀手清单 K1-K9：这些组合会互相咬

- **K1** 长记忆 × 大 top-K = 风险乘法（安全侧见 [agent-security-skills · llm-attack-surface](https://github.com/Focus688/agent-security-skills/blob/main/skills/llm-attack-surface/SKILL.md)）。写入保留率↑（风险库存↑）叠加检索曝光↑（K=1→7 使攻击成功率从 <12% 到 >36% 🔵）——「什么都记 + top10 全喂」的 agent 在两个轴同时拉满。防御放「管理阶段」（可解耦：攻击成功率 -62% 而效用仅 -3-5% 🔵），别指望排序。
- **K2** 自生成技能 × 无执行门 = 供应链污染（准入侧见 [agent-security-skills · skill-review-checklist](https://github.com/Focus688/agent-security-skills/blob/main/skills/skill-review-checklist/SKILL.md)）。一条坏技能会无条件注入未来所有任务上下文；缺陷技能入池后跨会话持续毒化 🔵。
- **K3** LLM 当自己的裁判 = 收敛到评委而非任务。PROCTOR 记录 11 种评估失败：读缓存答案拿 100% 满分掩盖 68% 真实能力、被污染的 ground truth 让优化器删掉正确规则 🔵。**防御：评测集混 canary——答案已知且正常流程拿不到的题，满分即报警。**
- **K4** 静态回放评测 × 换模型 = 系统性错排。换模型会重写 61-94% 后续动作、仅 3% 回放状态仍有效 ⚪（一手出处待补，见 references.md E）——用固定轨迹评测给「模型 A/B」打分，结论基本是噪声。**换主模型后必须跑固定回归题组，通过才切。**
- **K5** 工具/技能堆叠 × 上下文预算 = 注意力稀释。18→2 工具 +20pp（成功率 80%→100% 🟢，计数 🔵）；bloated toolset 是 Anthropic 点名的头号失败模式（人类工程师都说不清该用哪个工具，别指望 agent 说得清 🟡）。工具面当预算管，宁少勿多。
- **K6** 多 agent × 上下文耦合任务 = 隐含决策丢失。子 agent 各自误解子任务，组合阶段无法收拾 🟡；agent 间失调占全部失败 ~32% 🟢。
- **K7** 细粒度能力 × 小模型/短任务 = 开销反噬。复杂动作空间小模型学不动、短预算下长程机制反而拖累 🔵。长程机制必须「确认发散/确认多跳」后才激活（fail-closed）。
- **K8** 为某模型调好的 harness × 换模型 = 可能负收益。Opus 造的搜索 harness 换 Gemini 执行，重复查询率 10.1%→88.2% 🔵。**任何 combo 调优参数在模型升级后必须重测。**
- **K9** 推理状态编进检索组件 = 过拟合自己。表征在自家 agent 上涨、5 个未见基座 5/5 掉分 🔵——用结构化稳定信号（查询历史/访问日志），别用 agent 内部思维流。

## 📒 四、实机账本：十二维的案例与翻车（Hermes 生产实例）

**▍静态六维（出厂配置）**

- **① 人设** = 铁律系统非化妆，一条「事实必须工具亲验」压掉全部编造类错误——全系统收益最高的一行字。
- **② 工具** = 三层栈（CLI > 脚本 > 浏览器），坑位记录比工具本身值钱（GFW 下 push 必挂改走 gh api、sqlite3 CLI 被劫持改用 python stdlib）。
- **③ 搜索** = 多引擎 + 渠道实测档案 + 时效判据（抓过宏观源冻结一年不报错的真 bug：数据最新一期距今超阈值即视为失效，宁可不报）。
- **④ 记忆** = 双轨（注入层高信号 + 检索层全量 + 身份卡 + 三元组）。翻车：解释器升级致记忆服务静默挂而不自知——记忆是基建，基建也会塌，基建本身要进健康检查。
- **⑤ 模型池** = 分层（主/cron/降级/专项），最大坑是静默降级：provider 名错一个字母每条消息偷用备胎且探活全绿。💡 **验收路由必须查计费账单不能信绿灯**（与结论 9 互证）。
- **⑥ 知识库** = 流程 + 坑位 + 参考，审计过 10 个社区热门技能 10 个全有高危缺陷——社区技能是拿来审再用。

**▍动态六维（运行机制）**

- **⑦ 执行纪律**是第一分水岭——五条硬纪律：可查询事实必须工具亲验、算术/系统状态/时间禁心算、输出分「验证过/没验证」两级标注、发现错误立即承认修正、工具结果为空换策略不编。
- **⑧ 记忆写入口径**四问（该不该记/记在哪层/何时失效/与旧条目什么关系），失效结论显式作废不并行两个真相，但保留历史、检索排序让新结论压过旧的。
- **⑨ 三级进化**（在线 refine：复杂任务后即时沉淀 / 周日体检：技能进化评估 + 11 项偏误体检 / 失败入账：每个翻车案例写进失败账本附根因修复法）。但进化机制自身也要防「假装进步」——自动优化器曾对已归档技能空转一周且把评测噪声当进步。
- **⑩ 安全四防线**（装前审计隐藏字符扫描：HTML 注释/零宽字符/双向文本 / 输入白名单+解析 IP 校验+重定向逐跳验证 / 权限最小化：组件按需拉起+密钥 0600 / 威胁模型成文：明确防了什么、明确接受什么），红队复审修出 7 处真缺陷含「空快照误删整棵依赖树」。
- **⑪ 编排分工矩阵**（推理重派子代理/机械批量纯代码/关键步骤串行），子代理自报不算数、外部副作用必须回读验证——子代理看不到你的对话历史，给它的简报必须自带全部背景。
- **⑫ 失效判据三件套**——事先量化的失效判据 + 每周对账诚实判分 + 触发即收缩不恋战（一条产品线连续 5 周零增长主动砍，没有事先写下的判据这种决定永远下不了手）。

## ⚖️ 六、诚实校准

- 22 篇论据中 16 篇是 2026-08/09 arXiv 预印本，未经完整同行评审，数字可能随版本修订（已尽量挑带显著性检验/CI 的）；HV/MV=7.80× 仅在 SWE-bench 100 题子集、3 个模型上测得，作者自声明不具普适性 🟢；+90.2% 多 agent 数字来自厂商内部 eval（打折看待）；MAST +15.6% 是单一 benchmark。
